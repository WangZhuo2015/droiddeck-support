HELP & CONTACT / 使用帮助

Connect your way.

Connect to an Android device or VNC server you own or are authorized to control. RemoteOrbit does not provide a cloud remote-access service.

连接你拥有或获授权控制的 Android 设备或 VNC 服务器。RemoteOrbit 不提供云端远程访问服务。

Android Wireless Debugging / Android 无线调试

  1. Use iOS/iPadOS 17 or later and Android 11 or later.
  2. Connect both devices to a network that permits them to reach each other, and allow RemoteOrbit's Local Network permission.
  3. Enable Developer options and Wireless Debugging on Android.
  4. Open the Android tab in RemoteOrbit, pair by code or QR code, and select the paired device. Accept Android authorization prompts when shown.

将两台设备接入可互相访问的网络，允许本地网络权限，在 Android 上启用开发者选项和无线调试，再于 App 的 Android 标签页通过配对码或二维码配对并连接。

Android ADB TCP / Android 手动连接

For a device with ADB over TCP already enabled, enter its reachable IP address and port. Pairing and connection ports may differ. Legacy ADB TCP is unencrypted; use it only on trusted networks and never expose ADB to the public internet.

输入已启用 ADB TCP 的设备地址和端口。配对端口与连接端口可能不同。传统 ADB TCP 不加密，仅适合可信网络，请勿将 ADB 端口暴露到公网。

VNC desktop / VNC 远程桌面

  1. Enable a compatible VNC server or Screen Sharing on the destination computer and note its address and port.
  2. Make sure the computer is reachable from your iPhone or iPad; allow the connection through its firewall and network.
  3. Open the VNC tab, enter the server address, port and requested credentials, then connect.

VNC passwords are used for the current session and are not saved. Available security and encryption depend on the VNC server configuration; choose a trusted network or a secure network path. The app ends the session when it moves to the background.

先在目标电脑开启兼容的 VNC 服务或屏幕共享，确认地址和端口可访问；再于 VNC 标签页填写服务器信息与所需凭据。密码只用于当前会话，不保存。连接安全性取决于服务器配置，请使用可信网络或安全的网络通道。App 进入后台时会结束会话。

Troubleshooting / 排查问题

  • Check Local Network permission, addresses and ports. Wi-Fi changes can change an endpoint's address.
  • Guest networks, firewalls and client isolation may prevent either type of connection.
  • For Android, confirm Wireless Debugging is still enabled and use the current pairing or connection port.
  • For VNC, confirm the server is running and its authentication settings match the credentials entered.
  • Keep RemoteOrbit in the foreground. Photos access is needed only when saving an Android screenshot.

检查本地网络权限、地址与端口，确认网络没有开启客户端隔离。Android 连接还需检查无线调试和当前端口；VNC 连接还需检查服务器是否运行及认证设置。连接期间保持 App 在前台；保存 Android 截图时才需要照片写入权限。
